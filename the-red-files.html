The red files

Scope

Product design

The Red Files is a conceptual book cover series designed to explore the dramatic tension and psychological suspense of classic film noir. Built as a visual concept, the project uses a high-contrast palette of crimson red, stark black, and muted cream to mimic heavy cinematic shadows. Distorted spatial proportions and unsettling angles create a raw, graphic layout framework that heightens the narrative mystery. Anchoring this conceptual system, the bold geometry of the GC VANK typeface provides an aggressive, industrial structure that completes the noir aesthetic.

This project is an experimental editorial concept designed as a high-end visual homage to raw retro energy. Built on a strict multi-column Swiss grid system, the layout balances expansive white space with dense, vivid archival imagery.

Spatial tension and high-contrast typography elevate nostalgic imagery into a refined, contemporary print publication. The resulting conceptual framework explores how minimalist structural alignment can bring order and clarity to expressive historical content.
